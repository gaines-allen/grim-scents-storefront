# Grim Scents storefront rendering

This is a buildless static prototype. Open `dist/index.html` through a local web server to view it.

Included interactions:

- Full-screen hero film with staggered logo and Shop All reveal
- Responsive six-product collection grid
- Five-image quick view for every candle
- Illustrative add-to-bag drawer
- Story, candle-care, newsletter, and footer sections
- Reduced-motion fallback and mobile navigation

Placeholder content remains for the full brand origin, exact fragrance notes where they were not supplied, shipping and return policies, newsletter integration, checkout, and social links.

Only the six candles with verified source photographs are included. All products are shown at $15.
